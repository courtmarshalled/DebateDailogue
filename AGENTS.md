# Codex Editorial Instructions

This repository is the editorial production system for Jon's investigative AI debate series.

Before any editorial task:

1. Read `MASTER_PROMPT.md` for the editorial mission, agent roles, workflow, and acceptance criteria.
2. Read `EPISODE_PRODUCTION_BIBLE.md` for the series' editorial identity and dated production guidance.
3. Read the relevant episode's complete source material, script, applicable `AGENTS.md` instructions, live schema and validators.
4. Treat current explicit directions and active executable constraints as authoritative. If guidance conflicts, document and resolve the conflict; never weaken checks quietly.
5. Preserve all originals. Write revised versions, research, and reports to separate locations. Only the designated editor can change the canonical candidate.
6. Verify meaningful claims against inspected sources. Never invent citations, source access, quotations, cut timestamps, speaker identities, or host reactions.
7. Require both sides to be recognizable to an informed defender. Never equate a failed argument for God with disproof of God.
8. Target an engaging, comprehensible 20-minute finished video. Make the first 30-60 seconds outstanding without manufactured stakes.
9. Revise only to fix concrete issues, within the active repair-cycle budget. Preserve independent reviews and a change log.
10. Validate what is testable and report what is not. Never claim to have watched or heard media that was not examined.
11. Do not publish, merge, overwrite released content, or incur unapproved costs. Jon retains editorial and publication approval.

First episode input: `episodes/unicorn/reaction.json` (if supplied). If absent, record the blocker and build the reusable system without fabricating the episode.

The immediate goal is to implement the editorial workflow and apply it to the unicorn episode, providing a reviewable revised candidate and reports.
